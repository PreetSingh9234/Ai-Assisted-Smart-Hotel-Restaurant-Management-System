# Smart Hotel & Restaurant Management - Streamlit App

This repository now includes a full Streamlit-based web app version of the management dashboard.

## Run locally

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## What is included in Streamlit rewrite

- Dashboard KPIs and sales trend
- Orders management with filter and search
- Menu, inventory, customers, kitchen, and delivery views
- NORA assistant panel with domain-aware responses
- Custom HTML/CSS styling and embedded JavaScript clock widget
